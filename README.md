# FrameShift Command

A local-first Windows desktop companion for Elite Dangerous: Odyssey, built with Tauri 2, Rust, SQLite, React, and TypeScript. Journal events drive the orange/cyan dashboard. The installed application needs no Node.js, Python, or separate server.

Version **0.2.1** brings automatic nearby searches to the dashboard Mining Hotspots widget: one preferred actual hotspot per supported commodity, with system Copy, distance, ring and Mapped/Reported labels. It shares the Mining tab's saved 100–5,000 LY presets and refreshes on jumps even on other pages. Signed in-app updates, the portrait dashboard, engineer distance groups, ship photos and confirmed arrival alerts are included.
